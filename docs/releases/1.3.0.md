# ZeroModel 1.3.0 - One-Command Runtime Installation

**Status:** release preparation

## Main user-facing improvement

ZeroModel 1.3.0 makes the normal public installation path:

```powershell
python -m pip install zeromodel
```

That command installs the complete supported ZeroModel Python runtime.

## Internal packaging change

The previous core distribution named `zeromodel` has been separated into the
implementation distribution `zeromodel-core`. The Python import namespace is
unchanged:

```python
from zeromodel.core import LayoutRecipe, ScoreTable, VPMPolicyLookup, build_vpm
```

The `zeromodel` distribution is now a metadata-only umbrella package that
depends on the coordinated runtime family.

## Why

This keeps the repository modular internally while making the public install
experience simple:

```text
modular package architecture
+
one-command installation
```

Advanced users can still install individual components such as
`zeromodel-core`, `zeromodel-vision`, or `zeromodel-search` and receive only
their declared dependency closure.

## Upgrade

The release gate verifies the 1.2.0 to 1.3.0 transition explicitly:

```powershell
python -m pip install zeromodel==1.2.0
python -m pip install --upgrade --find-links <local-wheelhouse> zeromodel==1.3.0
python -m pip check
python -c "from zeromodel.core import ScoreTable"
```

No special migration instructions should be published unless this upgrade probe
fails during final release validation.
